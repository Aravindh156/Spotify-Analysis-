This project analyzes a large Spotify songs dataset using Python-based data analysis and machine learning techniques. The objective is to explore music trends, identify relationships between audio features such as danceability, energy, valence, and popularity, and derive meaningful insights through data visualization and clustering.

Features
Data cleaning and preprocessing
Exploratory Data Analysis (EDA)
Correlation analysis between song attributes
Visualization using Matplotlib & Seaborn
Feature engineering
Clustering songs based on audio characteristics
Trend analysis on popularity and genres
Tech Stack
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Jupyter Notebook
Dataset

Spotify songs dataset containing 50,000+ tracks with audio features and metadata.

Key Insights
Strong relationship between danceability and popularity
Identification of song clusters with similar audio profiles
Trends in energy, acousticness, and listener preferences
